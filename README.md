## 🚀 Sobre el Proyecto
Bienvenidos al repositorio de **MetaHogar**. Este sistema web full-stack ha sido diseñado para optimizar los procesos administrativos y de atención ciudadana en Morelos. 

En este proyecto aplicamos: **PHP, MySQL, CSS** y herramientas de control de versiones con **Git**.

## 💻 Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3, JavaScript.
* **Backend:** PHP.
* **Base de Datos:** MySQL.
* **Entorno:** Laragon / XAMPP.

## 📁 Estructura del Repositorio
El proyecto está organizado de la siguiente manera:

* `assets/`: Imágenes y recursos visuales.
* `config/`: Conexión a la base de datos MySQL.
* `views/`: Archivos PHP para la interfaz de usuario.
* `public/`: Archivos CSS y JS públicos.

## 🛠️ Instalación y Uso
1. Clona el repositorio: `git clone https://github.com/tu-usuario/metahogar.git`
2. Importa la base de datos `db_metahogar.sql` en tu servidor local.
3. Configura las credenciales en `config/database.php`.
4. ¡Listo para ejecutar!
